## 技术要点
- 雪花 SVG 路径：`M12 2.5v19M12 5l-2 2...` 一条 path 旋转 60°/120° 复制三次成六瓣，createSnowflakeSVG() 复用
- snow-layer z-index 998（飘在聊天窗前），aurora-layer z-index 1（背景层），均 pointer-events: none
- 粒子用 Web Animations API（element.animate），onfinish 自动 remove，避免 DOM 泄漏
- 雪花飘落用 animationend 自清理 + setInterval 补充，维持 24 片上限
